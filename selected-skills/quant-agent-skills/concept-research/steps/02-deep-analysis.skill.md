# Step 2-4: Multi-Agent 深度分析 + 辩论 + 裁决

## Step 2: 4 Agent 并行研究

每个 Agent 输出约 300 字核心发现 + 互评其他 Agent 至少 2 条。详细 Agent 定义见 `agents/` 目录。

| Agent | 文件 | 核心问题 |
|-------|------|---------|
| narrative-agent | `agents/narrative-agent.skill.md` | 这个故事的起源、催化剂、生命周期阶段？ |
| quant-agent | `agents/quant-agent.skill.md` | 概念指数量价形态？成分股涨幅排名？龙头是谁？ |
| stock-picker-agent | `agents/stock-picker-agent.skill.md` | 成分股里谁有基本面支撑？真龙vs假龙？ |
| risk-agent | `agents/risk-agent.skill.md` | 泡沫信号？集中度风险？退潮信号？ |

**输出规范**：
- 每个 Agent 输出 ≤300 字
- 互评：每个 Agent 至少评论 2 个其他 Agent 的发现
- 引用溯源：[A1]-[A4] 标记每条结论来源
- **🛑 研报全量阅读**：所有 Agent 必须完整阅读 Step 1 检索到的每一篇研报正文。禁止抽选/跳读/只看标题
- **🛑 四维度必须覆盖但权重自适应**：
  - 纯量价概念（如"短剧游戏"）→ narrative-agent + quant-agent 权重高
  - 有业绩支撑的概念（如"AI算力"）→ stock-picker-agent 权重高
  - 高波动/炒作型概念（如"低空经济"初期）→ risk-agent 权重高

## Step 3: Debate + Leader 辩论裁决

```
Debate Agent: 生成最强看多论点(3条) + 最强看空论点(3条)
Leader: 逐条裁决——哪些论点有证据支撑？哪些是噪音？
输出: 概念多空裁决书 (≤500字)
```

**Bull/Bear 同等标准**：看多和看空必须同样篇幅、同样证据标准。不能"看多一句带过、看空列十条"（反之亦然）。

**概念研究特有的辩论焦点**：
1. **叙事持续性**: 这个故事的催化剂能持续多久？（政策驱动看落地节奏，技术驱动看突破时间表，纯资金博弈看龙虎榜）
2. **龙头质量**: 领涨股有业绩支撑吗？还是纯叙事炒作？
3. **阶段判断分歧**: Agent 之间对叙事阶段的判断是否一致？分歧在哪？
4. **入场时机**: 即使方向对，现在的价格是不是已经price in了？

## Step 4: 概念预期差挖掘 + 三情景期望值

```
市场定价了什么？（概念当前热度隐含的预期）
你的判断和市场有什么不同？
三情景:
  - 叙事延续 (概率:高/中/低): 概念继续走强, 龙头CAGR ___%, 估值___
  - 基准情景 (概率:高/中/低): 概念横盘消化, 龙头CAGR ___%, 估值___
  - 叙事退潮 (概率:高/中/低): 概念降温, 龙头回撤 ___%, 估值收缩到___
期望回报 = Σ 概率 × 回报
交易建议: ACCUMULATE/WATCH/AVOID, 建议仓位 ___%, 入场区间 ___
```

**⚠️ 概率用定性判断（高/中/低），不编造精确百分比。**

### 概念预期差的特殊维度

概念研究的预期差不在估值（那是stock-research的事），在于**叙事阶段判断**：

| 预期差类型 | 示例 |
|-----------|------|
| **阶段误判** | 市场认为在加速期（追涨），你判断已进入扩散期后段（派发风险） |
| **龙头切换** | 市场追捧市值最大的成分股，但真龙其实是小市值的纯正标的 |
| **催化节奏** | 市场按"利好出尽"定价，但催化剂实际是系列事件（还有后续） |
| **跨市场** | A股概念已price in，但港股同业尚未反映（或反之） |
| **成分股变动** | 即将被纳入概念的股票（信息优势），尚未被市场关注 |
