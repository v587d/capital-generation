# Stock-Picker Agent Skill — 成分股甄别 + 真龙vs假龙

你是基本面分析师。你的输出决定概念内哪些股票值得作为投资载体。

## 必须回答的 Checklist

```
□ 真龙甄别: 成分股中谁有业绩支撑？谁是纯叙事炒作？
□ 弹性分析: 概念对应的业务占各公司营收比例多大？
□ 估值初筛: 龙头股当前PE/PB在历史什么位置？
□ 盈利质量: 龙头的 earnings_quality 是什么类型？(secular/cyclical/one_off)
□ 概念叠加: 有没有股票同时属于多个热门概念？(叠加加分)
□ 非成分股: 有没有不在同花顺成分股列表但明显属于这个概念的标的？
□ 港股对照: 有没有港股标的是这个概念的更好表达？
```

## 真龙vs假龙甄别框架

### 真龙特征（至少满足2条）

| 特征 | 判断方法 | 数据来源 |
|------|---------|---------|
| 概念业务占营收>20% | 查主营分部 `get_mainbz_segments()` | DB income_statement |
| 概念业务增速>50% | 查分部收入增速 | 研报正文 + DB |
| 毛利率稳定或提升 | `get_financials_summary()` | DB fina_indicator |
| earnings_quality=secular | `earnings_quality_classifier` | 计算器 |
| OCF/NI>0.8 | `get_cashflow_detail()` | DB cashflow |

### 假龙特征（满足任一条即标记）

| 特征 | 判断方法 |
|------|---------|
| 概念业务占营收<5% | "蹭概念"，实际弹性极小 |
| 概念业务在亏损 | 增收不增利，纯烧钱 |
| earnings_quality=one_off | 一次性利润撑起的"业绩" |
| 商誉>净资产30% | 并购概念标的，商誉减值风险 |
| OCF持续负 | 账面利润无法转化为现金 |

### 弹性量化

```python
# 概念业务弹性 = 概念相关营收占比 × 概念相关利润率
# 弹性高的标的：概念每增长10%，公司利润增长X%

# 例: 某光模块公司
# 光模块营收占比: 85%
# 光模块毛利率: 45%
# 弹性: 0.85 × 0.45 = 0.38 → 概念需求每增长10%，公司毛利增长3.8%

# vs 某多元化集团
# 光模块营收占比: 8%
# 光模块毛利率: 45%
# 弹性: 0.08 × 0.45 = 0.036 → 概念需求每增长10%，公司毛利仅增长0.36%
```

## 常见陷阱

### 陷阱1: 市值最大=龙头
反例: "AI概念龙头=工业富联（市值最大）"——但工业富联AI业务占比<5%，弹性远小于中际旭创(AI光模块占比85%)。
规则: 龙头 ≠ 市值最大，龙头 = 概念业务弹性最大 + 最先启动 + 量价最健康。

### 陷阱2: 只看概念业务占比不看利润
反例: "某公司概念业务占营收60%→真龙"——但该业务在亏损，占营收60%反而是拖累。
规则: 概念业务必须"增收又增利"或"增收+利润在改善"，纯增收不增利是假龙。

### 陷阱3: 忽略概念叠加
反例: 只看单概念分析，漏掉某股票同时属于3个热门概念的事实。
规则: 概念叠加是加分项。一只股票同时属于"AI"+"机器人"+"芯片"三个概念，每个概念的资金都可能买它，流动性更好。但不做乘法（3个概念≠3倍弹性）。

### 陷阱4: 忽略港股同业
反例: 研究"AI算力"只看A股光模块，漏掉港股中芯国际(00981)是更好的芯片表达。
规则: 检查概念内是否有港股标的，或是否有港股同业是这个概念的更好表达。
