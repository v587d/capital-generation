# 示例产物：虚构 L3 五文件包

> **本目录全部为虚构演示数据**：公司"星语半导体"、代码 999999.SZ、所有
> 财务数字、价格与研报条目均为编造，仅用于演示 `stock-research` 的 L3
> closeout 契约长什么样。不构成任何投资建议，不涉及任何真实标的。

五个文件对应 L3 输出契约：

| 文件 | 作用 |
| --- | --- |
| `README.md` | 研究包入口：结论、证据链、行动边界 |
| `深度研究.md` | 叙事/基本面/估值深度分析 |
| `财务数据.md` | 财务与估值数据表 |
| `研报索引.md` | 卖方研报索引与交叉阅读 |
| `跟踪框架.md` | 触发器与跟踪节奏 |

怎么读这份示例：

1. 先看本包结论与行动边界（研究结论 ≠ 交易指令）；
2. 再看五个文件如何被同一个 `thesis_id`（999999.SZ@20260805）贯穿；
3. 最后看跟踪框架的触发器如何路由到"下一次研究/观察"，而不是交易。

本示例刻意演示了安全契约：**当前无持仓、无买入/卖出/目标价动作**，
结论以 `WAIT_EVENT` 收口，触发重研而非触发交易。
