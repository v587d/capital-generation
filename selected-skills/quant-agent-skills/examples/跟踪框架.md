# 跟踪框架：星语半导体（虚构示例）

## 一、触发器（机器可读）

| trigger_id | 事件 | 类型 | 路由 |
| --- | --- | --- | --- |
| T-01 | 大客户定点公告披露 | `expectation_delta_event` | 触发重研（L2 复核） |
| T-02 | 季度经营现金流/净利润 < 0.7 | 财报 | 触发财务专项复核 |
| T-03 | 存货周转天数连续两季上升 | 财报 | 触发渠道健康度复核 |
| T-04 | 行业产能周期见顶信号 | 产业数据 | 触发行业重研 |

全部 trigger 只路由到 `re_research` 或 `watch`，**不产出交易动作**。

## 二、Review 节奏

- 月度：跑一遍五文件 freshness check；
- 季报后：更新财务数据 + 预期差对账；
- 任何 trigger 触发后：24 小时内完成重研路由登记。

## 三、KPI（对研究本身）

- 预测可证伪：每次重研必须写下可证伪的预期（如"定点若落地，收入上修
  概率 X%"）；
- 跟踪命中率：每季度复盘 trigger 命中与误报，沉淀进 skill 规则。

## 四、与 SSoT 的衔接（演示）

- 本包结论写入 `research_verdicts.json`（999999.SZ 条目，action=
  `watch`）；
- 触发器写入 `catalyst_events`；
- 观察池登记 `watchlist.json`（**未持仓观察池**，不进入持仓映射桥）；
- 以上均为研究状态，非交易状态。
