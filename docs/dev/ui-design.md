# UI/UX 设计规章（§13）

> 索引见仓库根 `AGENTS.md` §13；改设置卡、自动化页、自选股弹窗或任何 host 平面界面前读本页。
> 本文只写界面决策、控件语义与自查；业务规则仍住各自文档。截图、尺寸和状态以现有页面为基准，
> 不要凭感觉新造一套。

## 13.1 控件与视觉

**先复用，再抽象。** 表单控件优先用 `@deepseek-ai/dsh-client-ui-primitives` 的官方件：
`SettingsForm` / `SettingsSecretField` / `SegmentedControl` / `Switch` / `Modal` / `Menu`。
某项能力官方没给时，先看同仓库页面有没有实现；自动化页的 `Select`（`automation/client.src.cjs`）
就是「胶囊触发器 + 宿主 `Menu`」的参考实现，设置卡的工作区下拉（`config/client.src.cjs` 的
`WorkspaceSelect`）照抄这套行为，而不是各写一份。

**⛔ 禁止原生 `<select>` / `<input type="date">` 装点门面。**
原生控件的弹层由浏览器绘制，配色、圆角、焦点环和键盘行为都不受宿主 token 控制；浅色模式下还会
出现系统白底、系统蓝选中条。所有下拉都用「按钮触发器 + 官方 `Menu`」，输入型日期仍用文本/数字
输入或宿主提供的日期件。

**视觉 token 只有一套。** 颜色、边框、圆角、间距、字号全部从 `--dsw-alias-*` 派生；亮暗主题
不各写一份硬编码色值。当前基准：

- 触发器：高 34px、圆角 10px、字号 12.5px / 行高 20px，左右内边距 10–12px；
- 底色：`--dsw-alias-bg-module-platform`；悬停：`--dsw-alias-interactive-bg-hover`；
- 文字：`--dsw-alias-label-primary`；次要说明：`--dsw-alias-label-tertiary`；
- 焦点：`--dsw-focus-ring-color`（缺省用品牌色）2px outline，偏移 0；
- 禁用：透明度 0.5 + `cursor: not-allowed`，不允许仍能 Tab 进弹层。

**间距和分组跟信息结构走。** 同一面板内的字段纵向 gap 保持 8–16px 一档；只有一个字段的组
不要再套一层 group label，字段标题本身已经承担分组。路径、默认值这类说明放控件下方一行，
不写重复解释句（例如「任务未指定时使用此工作区」——标签和默认项已经说明）。

## 13.2 文案、布局与回归

**文案只写动作必需的信息。** 控件已表达的默认值、路径、选中态不再用第二句话重复；错误提示
带允许范围与下一步动作，不写「保存失败，请重试」以外的诊断术语。删除说明句后，控件仍要能被
第一次使用的人理解。

**交互闭环必须完整。** 下拉打开后：点击外部关闭、Esc 关闭、选择后关闭、禁用时关闭、父组件卸载
时关闭；关闭后焦点回触发器。触发器带 `aria-haspopup="menu"`、`aria-expanded` 与可读的
`aria-label`；选中项由 `Menu.selectedId` 标出。长工作区名 / 路径用省略号截断，不把触发器撑破。

**响应式先按 320–400px 宽检查。** 窄屏下下拉、路径和按钮不能互相挤压；弹层可以比触发器宽，
但不得超出视口或制造第二个滚动容器。日期/时间等原生输入若必须保留，至少设置 `color-scheme`
跟随明暗主题。

**改完必须补客户端断言。**
- 渲染：控件类型（按钮 + `Menu`，不是 `select`）、`aria-*`、选中态、禁用态、缺失项；
- 写入：`scope.mutate` 的叶子路径与 payload；
- 样式表：关键尺寸 / token / 焦点 / 禁用规则；旧原生控件的样式规则必须消失；
- 全量：`npm test` 与 host / 客户端改动后的 `npm run check:dsh` 全绿后才算完成。

**设计走查顺序。** ① 先看同页现有控件，选中离需求最近的那一个；② 再看设置卡 / 自动化页的
亮暗两套截图；③ 最后才决定是否新增 CSS 变量或组件。新增公共控件时，把参考实现、状态清单和
回归断言写进本页，避免下一次又从零发明。
